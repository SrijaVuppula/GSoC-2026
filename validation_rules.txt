Required core fields for sample submission:
- organism
- sample_type
- collection_location
- collection_date
- condition_or_disease

Validation rules:
- organism must be a recognized scientific name or controlled value
- sample_type must not be empty
- collection_location must not be empty
- collection_date should be in YYYY-MM-DD format if available
- condition_or_disease can be null only if explicitly unknown

Clarification behavior:
- if a required field is missing, ask a follow-up question
- if a field is ambiguous, ask for disambiguation
- if all required fields are present, mark the record as ready_for_submission
